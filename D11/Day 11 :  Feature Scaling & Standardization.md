# Day 11 — Feature Scaling & Standardization

## Objective

Learn how to scale numerical features before applying Machine Learning algorithms.

## Topics Covered

* Feature Scaling
* Standardization
* Normalization
* StandardScaler
* MinMaxScaler
* Comparing original and scaled data

## Dataset

A small sample dataset containing:

* Age
* Salary
* Experience

## Methods Used

### StandardScaler

Standardizes features so that they have approximately:

* Mean = 0
* Standard deviation = 1

### MinMaxScaler

Transforms features into a specified range. By default:

* Minimum = 0
* Maximum = 1

## Key Learning

Machine Learning features can have very different numerical ranges. Feature scaling puts numerical features on a comparable scale and is particularly important for algorithms that are sensitive to feature magnitude or distance.
