# Day 14 - K-Means Clustering

## Objective

Learn and implement K-Means Clustering, an unsupervised machine learning algorithm.

## Concepts Learned

- Unsupervised Learning
- Clustering
- K-Means Algorithm
- Cluster Centers
- Cluster Labels
- Elbow Method
- Inertia
- Data Visualization

## Algorithm

1. Choose the number of clusters K.
2. Initialize cluster centers.
3. Assign each data point to the nearest center.
4. Calculate new cluster centers.
5. Repeat until the clusters stabilize.

## Technologies

- Python
- NumPy
- Matplotlib
- Scikit-learn

## Result

Successfully implemented K-Means Clustering and visualized customer groups.

## AIML Relevance

K-Means can be used for customer segmentation, pattern discovery, recommendation systems, and exploratory data analysis.
