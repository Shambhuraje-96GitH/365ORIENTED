# Day 8 — Logistic Regression

## Objective

Learn the fundamentals of Logistic Regression and use it to solve a binary classification problem.

## Concepts Learned

* Classification
* Logistic Regression
* Binary classification
* Sigmoid function
* Training and testing data
* Model prediction
* Accuracy
* Confusion matrix
* Precision
* Recall
* F1-score
* Prediction probability

## Dataset

The dataset contains:

* StudyHours
* Attendance
* Passed

The target variable is `Passed`.

`0` = Fail
`1` = Pass

## Model Used

Logistic Regression from Scikit-learn.

## Evaluation Metrics

The model was evaluated using:

* Accuracy
* Confusion Matrix
* Classification Report

## Practical Experiment

Different combinations of study hours and attendance were provided to the trained model to observe how its predictions changed.

## AIML Engineering Learning

Logistic Regression is an important machine learning classification algorithm used for predicting categorical outcomes. Understanding classification algorithms is an essential foundation for developing machine learning systems.

## Day 8 Outcome

Successfully trained and evaluated a Logistic Regression model and used it to make predictions on new data.
