
# Day 43 - Gated Recurrent Unit (GRU) Networks

## Aim
To implement a GRU deep learning model
for electricity consumption forecasting.

## Objective
- Understand GRU architecture.
- Learn update and reset gates.
- Generate sequential time-series data.
- Train a GRU neural network.
- Predict future electricity consumption.
- Evaluate prediction performance.

## Technologies Used
- Python
- NumPy
- Matplotlib
- Scikit-learn
- TensorFlow / Keras

## Algorithm
1. Generate electricity consumption data.
2. Normalize the dataset.
3. Create time-series sequences.
4. Divide data into training and testing sets.
5. Build a GRU model.
6. Compile and train the model.
7. Predict electricity consumption.
8. Evaluate using Mean Squared Error.
9. Visualize actual and predicted values.

## Installation

pip install numpy matplotlib scikit-learn tensorflow

## Execution

python GRU_Networks.py

## Expected Output
- GRU model training progress.
- Mean Squared Error.
- Actual vs predicted consumption graph.

## Conclusion
Successfully implemented a GRU neural network
for sequential electricity consumption forecasting.
