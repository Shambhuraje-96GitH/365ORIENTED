
# Day 45 : Attention Mechanism

## Objective
To implement the Attention Mechanism using PyTorch.

## Concepts Covered
- Query, Key and Value
- Scaled Dot-Product Attention
- Softmax Function
- Attention Weights
- Context Representation

## Installation
pip install torch

## Execution
python Attention_Mechanism.py

## Expected Output
Input Shape: torch.Size([1, 5, 8])
Attention Output: torch.Size([1, 5, 8])
Attention Weights: 5x5 attention matrix

## Learning Outcome
Understand how attention assigns importance
to different elements in sequential data.
