
# Day 38 - Content-Based Filtering Recommendation System

## Objective
Build a Content-Based Movie Recommendation System
using TF-IDF Vectorization and Cosine Similarity.

## Concepts Covered
1. Content-Based Filtering
2. Feature Extraction
3. TF-IDF Vectorization
4. Cosine Similarity
5. Movie Recommendation
6. Text Feature Processing

## Technologies Used
- Python
- Pandas
- Scikit-learn

## How It Works

1. Create a movie dataset.
2. Extract movie descriptions.
3. Convert text into numerical TF-IDF vectors.
4. Calculate cosine similarity.
5. Identify movies with similar content.
6. Recommend the most similar movies.

## Installation

pip install pandas scikit-learn

## Execution

python "Day 38 - Content Based Filtering.py"

## Real-World Applications

- Netflix movie recommendations
- Amazon product recommendations
- Spotify music recommendations
- News article recommendations
- Online learning recommendations

## Learning Outcomes

Understand how content-based recommendation
systems use item features to generate suggestions.

## Challenge

1. Add at least 20 movies.
2. Include genres, actors and directors.
3. Experiment with different TF-IDF settings.
4. Compare recommendation results.
