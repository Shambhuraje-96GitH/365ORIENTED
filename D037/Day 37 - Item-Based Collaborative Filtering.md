
# Day 37 - Item-Based Collaborative Filtering

## Objective :
Implement an Item-Based Collaborative Filtering recommendation
system using Python and Cosine Similarity.

## Concepts Covered
1. Recommendation Systems
2. Collaborative Filtering
3. User-Item Rating Matrix
4. Item-Item Similarity
5. Cosine Similarity
6. Movie Recommendations

## Technologies Used
- Python
- Pandas
- Scikit-learn

## How It Works

Item-Based Collaborative Filtering recommends items
based on their similarity to items a user has already rated.

Steps:
1. Create a user-item rating matrix.
2. Calculate similarity between items.
3. Apply Cosine Similarity.
4. Rank similar items.
5. Generate recommendations.
