# Day 6 : Data Cleaning and Preprocessing

## Objective

Learn how to identify and clean common problems
in real-world datasets using Pandas.

## Topics Covered

- Missing values
- Mean and median
- fillna()
- Duplicate detection
- drop_duplicates()
- Data types
- astype()
- DataFrame filtering

## AIML Relevance

Data cleaning is an important step in the machine learning
pipeline because machine learning models require reliable
and properly prepared data.

## Practice

Created a small employee dataset containing missing values
and duplicate records and cleaned the dataset using Pandas.
