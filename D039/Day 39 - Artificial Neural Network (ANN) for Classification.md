
# Day 39 - Artificial Neural Network (ANN) for Classification

## Overview
Implemented an Artificial Neural Network (ANN) using
Scikit-learn to perform multiclass classification on
the Iris dataset.

## Objectives
- Understand Artificial Neural Networks.
- Learn the architecture of neural networks.
- Implement input, hidden, and output layers.
- Understand activation functions.
- Perform feature scaling.
- Train an ANN using backpropagation.
- Evaluate classification performance.

## Technologies Used
- Python
- NumPy
- Matplotlib
- Scikit-learn

## Dataset
Iris Dataset

The dataset contains:
- 150 samples
- 4 input features
- 3 target classes

Target Classes:
1. Setosa
2. Versicolor
3. Virginica

## ANN Architecture

Input Layer:
4 neurons

Hidden Layer 1:
64 neurons

Hidden Layer 2:
32 neurons

Output Layer:
3 classes

Activation Function:
ReLU

Optimizer:
Adam

## Implementation Steps
1. Load the Iris dataset.
2. Split data into training and testing sets.
3. Standardize input features.
4. Initialize the ANN classifier.
5. Train the neural network.
6. Generate predictions.
7. Evaluate model performance.
8. Visualize the confusion matrix.
9. Analyze the training loss curve.
10. Predict a new sample.

## Evaluation Metrics
- Accuracy
- Precision
- Recall
- F1-score
- Confusion Matrix

## Execution

Install dependencies:

pip install numpy matplotlib scikit-learn

Run the Python file:

python Day39_ANN_Classification.py

## Learning Outcomes
- Understanding neural network architecture.
- Implementing multilayer perceptrons.
- Understanding forward propagation and backpropagation.
- Applying ANN to classification problems.
- Evaluating deep learning models.

## Conclusion
Successfully implemented an Artificial Neural Network
for multiclass classification using the Iris dataset.

The project demonstrates how neural networks learn
patterns from data and generate classification predictions.
