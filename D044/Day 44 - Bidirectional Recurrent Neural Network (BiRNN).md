
# Day 44 - Bidirectional Recurrent Neural Network (BiRNN)

## Objective
To understand and implement a Bidirectional RNN
for electricity consumption forecasting.

## Concepts Covered
- Traditional RNN
- Bidirectional RNN architecture
- Forward and backward propagation through sequences
- Sequence creation
- Data normalization
- Model training
- Model evaluation using MSE
- Data visualization

## Technologies Used
- Python
- NumPy
- Matplotlib
- Scikit-learn
- TensorFlow / Keras

## Installation

pip install numpy matplotlib scikit-learn tensorflow

## Execution

python Bidirectional_RNN.py

## Expected Output

1. Model training information.
2. Predicted electricity consumption values.
3. Mean Squared Error (MSE).
4. Actual vs Predicted consumption graph.

## Learning Outcome

Successfully implemented a Bidirectional RNN
using TensorFlow/Keras and understood how
bidirectional processing works on sequential data.
